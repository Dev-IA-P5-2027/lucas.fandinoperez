# Building a Machine Translation Demo with LLMs + Gradio

## Instruction :

* **Search and use a benchmark translation dataset** (with original + reference text) from Kaggle, HuggingFace, etc.
* **Build a translator app demo** using **one LLM from Ollama** and **one LLM from HuggingFace** (It can be for English to French, or French to English, depending on the dataset you have).
* **Use different temperature settings:** 0, 0.2, 0.5, 0.8, 1.0
* **Evaluate results** using BLEU and ROUGE scores.
* **Deploy an interactive demo app** using Gradio in your local machine.
* **Upload your complete code to GitHub.** Add a report comparing the performance of the tested model and a demo video to the README, then share the repository link with me.
